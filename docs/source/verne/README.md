# Source text: Vingt mille lieues sous les mers

The project's only source for the scenario and dialogue. Downloaded 2026-11-22.

| File | Text | Origin | Rights |
|---|---|---|---|
| `fr-verne-5097.txt` | Jules Verne, original French (Hetzel), Part 1 and Part 2, 47 chapters | Project Gutenberg #5097, via the gutenberg.pglaf.org mirror | Public domain |

## Rules for using the text

- Write the game's French lines from this text, and write the English lines ourselves.
- Don't bring copyrighted translations into the repo or the script. F. P. Walter's English translation (1999) is still under copyright and was deliberately removed.
- Don't use the old Mercier Lewis translation (1872) either. It is public domain, but it cuts about a fifth of the text and has many errors.
- Draw Nautilus and creature designs from Verne's descriptions, not from Disney's 1954 film.
- The Gutenberg file keeps its licence header and footer. Leave them in place.
