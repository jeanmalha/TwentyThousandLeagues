# Engravings

From the 1871 Hetzel edition of *Vingt mille lieues sous les mers*, drawn by Alphonse de Neuville and Édouard Riou and engraved by Hildibrand. **Public domain.** Scans: Bibliothèque nationale de France (Gallica, btv1b2200238g), via Wikimedia Commons, "Illustrations de Vingt mille lieues sous les mers - A. de Neuville, Riou, dess. ; Hildibrand, grav. ; Jules Verne, aut. du texte - btv1b2200238g (NNN of 113).jpg".

`hetzel-NNN.jpg` is page NNN of that set, with the engraving cropped from the page and tinted like printed paper by `tools/art-pipeline/engravings.py`. Only the engravings the chapters use are kept here; rerun the tool to add others.
