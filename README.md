# Twenty Thousand Leagues

A 16-bit-style, first-person adventure game adapted from Jules Verne's *Vingt mille lieues sous les mers* (1869–1870), built with Godot 4.6.

Work is tracked on the kagen board **TTLUTS**. Instructions for contributors and agents are in [docs/kagen/README.md](docs/kagen/README.md).
